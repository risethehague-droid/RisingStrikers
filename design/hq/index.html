How HQ works
  1. Add anything with + Add a card: an idea, a bug, a task, a question. It lands in To do as New.
  2. Claude (the taskmaster) sorts it, writes the brief and hands it to a worker: worker-l on Luca's account or worker-f on the friend's. Each worker reports into the agents folder on GitHub; the taskmaster check reviews every report before the card comes to you. It runs 3 times a day (08:39, 13:39, 20:39); ⚡ Turbo (Luca only) makes it every 2 hours (08:39 to 22:39) while you're actively working, at more usage. The nightly QA run (01:44) plays simulated matches and puts any fixes here too.
  3. The Agents row is worked out from the cards: a worker's card in progress = Working, waiting for your OK = Waiting, and so on.
  4. YOUR MOVE lists what waits for you. Each card says who picks it up if you OK it (the taskmaster merges, or a worker builds the next step). OK = go ahead. Not yet = back with your note. No = dropped. An OK'd card shows on that agent in the Agents row.
  5. A pull request's card shows its preview: the GIF from the PR playing (click it to make it bigger), ▶ Play it (that PR's code as a game, on a computer) and Test Lab: CH1 (the test with that PR's code). vs today opens the same test in today's official Test Lab, so you can compare.
  6. ↻ Check now (Luca only) runs a quick taskmaster check straight away instead of waiting for the next scheduled check: new PR cards and their previews land 5-10 minutes later (it starts a fresh cloud session each time, which takes a few minutes by itself). Report reviews, which run test matches, stay with the scheduled check. It costs one check's worth of usage each time.
  7. The tags in square brackets say where the work happens: cloud, your laptop, PixelLab, Aseprite, claude.ai, GitHub.
  8. Loose Ends lists work stuck between two stages, with what closes it and who it waits on. Make a card turns one into a card on the board (it shows as Sent); Close settles it, with a line saying how.
  9. Messages is where Luca, the co-designer and the agents leave each other notes. Pick who it's to, write, send. Replies sit under the message; Answered closes it. The taskmaster check reads new messages first, answers what it can and leaves a short summary after each run.
  10. Versions lists every game version, newest first, with its PRs, whose OK, the changes and their preview GIFs. Search it ("keeper"), or show only what's new since you last looked (remembered in this browser).
  11. Project holds the roadmap (with progress by estimated hours), the art and game files, the decisions made so far and the references.
  12. The menu on the left jumps to each section. Every section has its own link: HQ's link plus #agents, #your-move, #board, #loose-ends, #messages, #versions, #project (or a tab: #roadmap, #creative, #assets, #decisions, #references) or #how.
