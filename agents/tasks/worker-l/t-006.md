**1. INSTA FLAG** (any match the human plays, watch mode too; not the Lab)
- **F** (and the gamepad's BACK / SELECT, and a small clickable flag button in a top corner of the HUD) pauses the game
  and opens a small overlay in the existing `#flow` look: "FLAG A PROBLEM", a text box with focus, SEND / CANCEL
  (ENTER sends, ESC cancels). Typing must not move players or trigger game keys.
- Under the box, one line: "SPEAK INSTEAD: WIN + H (WINDOWS) / FN FN (MAC) TYPES WHAT YOU SAY". (A microphone isn't
  available inside a claude.ai page, so dictation into the box is how voice works.)
- SEND saves a clip of the **last 8 seconds** (extend the recording buffer if it holds less) the way Bug Watch saves
  its clips (`replay.js`, the game page's database, collection `bugwatch`), as `kind: 'flag'` with: the note, the game
  version, teams, score, clock and half, difficulty, team AI, pace (if PACE exists on your base), the camera, and a
  repro line if Bug Watch can make one. Then "FLAGGED ✓ · THANKS" for a second and the game resumes.
- **"Then instantly start working on fixing"**: after a successful save, call the Claude Code Remote connector to wake
  the fixer, exactly like HC2 HQ's "Check now" does:
  `const mcp = await claude.use('mcp'); await mcp.callTool('Claude Code Remote', 'fire_trigger', { trigger_id: FLAG_TRIGGER, text: 'FLAG <clip id>: <note>' })`.
  Put `FLAG_TRIGGER` in `replay.js` as `''` for now: the taskmaster creates the fixer task, fills in the id and adds the
  `mcp` capability to the game page when it merges. With `''`, or when `claude.use('mcp')` gives `null`, or the call
  fails, skip it quietly (the clip is still saved). Never block play on it.
- Watch mode's N (mark a moment) and the full-time review keep working; flags show up in the Bug Watch review list
  too, marked FLAG.

**2. REPLAY CONTROLS** (the replay menu)
- A pause-menu item **REPLAY (LAST 10 S)** opens the most recent frames. LAST GOAL, HIGHLIGHTS, Bug Watch clips and
  flag clips open in the same player.
- Controls, on screen as a small bar with clickable buttons and on keys:
  - play / pause (PASS key or SPACE)
  - slow-mo 1x / 0.5x / 0.25x (up / down)
  - step one frame back / forward while paused (left / right tap); hold left / right to scrub
  - restart; exit (ENTER or SHOOT)
- The automatic goal replay during a match stays as it is (quick, any key skips: ARCADE PACE wants that).

**3. EVERY EFFECT IN REPLAYS**
- Audit what a replay leaves out today and record it: special-shot effects (fire, lightning, after-images, rings, the
  rough rigs' moved / turned frames for `sp1` / `sp2` / `super` and the aerial specials), keeper special-save effects,
  the ball's trail and spin look, hit-stop flashes, the shot's squash. Record each as events on the recording (frame
  number + what to draw) and draw them again in the replay, in slow-mo too.
- The special-save cut scene doesn't need to replay in full; a short flash of its band is enough.
