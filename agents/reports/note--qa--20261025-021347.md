## 2. Bugs
- **Shots count lower than "shots on target"** in every soak match (e.g. #1: shots 5-3 = 8, on target 12; all 12: shots 98, on target 150).
  - What you'd see: the match stats undercount shots.
  - Repro: any match, e.g. `ONE='seed=1000 home=IS away=IRO lvl=easy ai=new weather=clear tod=day' node tools/soak.js`.
  - Guess: `shots` is only counted for ground shots and tap kicks (`ball.js` doShot / tapKick). Headers, volleys, chips and specials never add one, while the keeper's "on target" counter (`keeper.js` planSave) counts every one of those, and maybe twice when he re-reads the same shot.
  - Not fixed: keeper.js is on worker-f's open t-016, and ball.js is held for t-015's follow-ups. Needs a small task.
- **FLOW_STUCK ×1**: a kick by IS #8 "hung for 3 s" at 42' (#8, IRO v IS, rise, classic AI). Already there in v0.10.4 (changelog). The match did go on and finished normally.
  - Repro: `MATCHES=8 node tools/soak.js` (match #8). The `ONE=` line alone plays a different match (next bug).
  - Guess: a kick that waits for its animation's contact frame (`m.pending`), and the animation never reaches it, so something else releases it later.
- **Soak repro lines don't replay on their own.** `ONE='seed=56433 …'` gives 0-2 with shots 4-6 and no FLOW_STUCK; the same seed as match #8 of the series gives 0-2, shots 4-5 and the FLOW_STUCK.
  - Why: the soak plays all matches on one page, and a lot of match state carries over to the next match: the game clock (`time.now`), the aerial-special clock and last one used (`aerialClock`, `airLast`), the last keeper special (`gkSpLast`), the ball's shot / special timers, and the camera.
  - The series itself is exact (tonight = the v0.11.0 changelog's numbers, to the trip). So for now replay match n with `MATCHES=n`.
  - Worth a check: the same carry-over may happen in the real game when you play a second match without reloading (e.g. a special "cooling down" from the last match). Not fixed: it's match-start code (matchflow.js, held for t-015).
- **ANIM_FLICKER** (208 trips, every match): 15 of the 24 example clips were false alarms. Bug Watch counted the blank animation name (the game's "replay the move" reset) as a picture. **Fixed: PR #21.** What's left is real: a run / touch picture showing for 1-2 frames just before a pass or jockey.
