# V7 Y68m9k60Lg0 - Images Pro Flash, Skeleton V3 & PixMiniMax (newest update; most relevant)
IMAGES
- "Create image Pro Flash" in the web Creator. Prompt body type in words (tall, skinny, small head) -> works.
- STYLE IMAGE: drop in a sprite whose look you like -> it copies proportions, rendering, shading (not the character). Then every new asset (heroes, enemies, props, VFX) shares one look.
- One extra word ("shorter") changes proportions but keeps the style.
- "Edit image Pro Flash": same character, new outfit / material / state (walk, hurt, sleeping). Chain edits: feed the last result back in.
- Always say "front-facing" (or the direction) or it may turn sideways.
- Inpainting Pro (Aseprite/Pixelorama/map editor), model Pro Flash: paint a mask over head/torso/legs, prompt hair / shirt / pants, generate ON A NEW LAYER + remove background -> you get a clean OVERLAY piece. Mask must fully cover the area. Retry if flat.
  -> This is exactly our modular hair / beard / kit idea: generate each piece as an overlay layer.
ANIMATION
- "Animate with text" + PixMiniMax: frame 1 = your image; prompt e.g. walk loop / breathing idle / slam attack; use ENHANCE PROMPT; 12-16 frames (up to 40).
- Give room: resize canvas bigger (e.g. 64 -> 80) before big motions.
- "Create character" button sends an image into the Character Creator; V3 generation mode makes the directions.
- Skeleton V3: templates (walk 8 frames etc.) are now good -> recommended. Always clean up afterwards.
- 8-direction custom animations: enhanced prompt says "towards the camera" -> wrong for NE/N/NW. Edit the prompt per direction under advanced options, re-enhance.
- State colours of effects explicitly (it drifted purple/red).
- MIRROR a good direction (NW -> NE) instead of regenerating = more consistent.
- Clean LOOPS: use the same frame as first AND last frame, then drop the duplicate.
